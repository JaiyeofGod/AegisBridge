# ADR-018 — Repository Root Name AegisBridge

**Status:** Accepted  
**Date:** October 20, 2026

## Context

Master requirements illustrate a tree under `aegis-security-platform/`. The working directory is `AegisBridge`.

## Decision

Keep the workspace / repository root name **AegisBridge**. Internal layout still follows the master monorepo structure (`apps/`, `migrations/`, `docs/`, etc.).

## Alternatives

- Rename folder/repo to `aegis-security-platform`

## Consequences

+ No disruptive rename  
− Docs referring to the illustrative name should mean this root
