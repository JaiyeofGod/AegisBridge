# ADR-006 — Use NIST CSF 2.0 as Top-Level Framework

**Status:** Accepted  
**Date:** October 20, 2026

## Context

The GRC program needs an organizational framework for Govern/Identify/Protect/Detect/Respond/Recover with Current/Target profiles.

## Decision

Use **NIST Cybersecurity Framework 2.0** as the top-level organizational framework. Use CIS Controls v8.1 IG1 for concrete practices and selected NIST SP 800-53 Rev. 5 / OSCAL content for detailed controls. Prefer machine-readable official sources; do not republish licensed CIS content inappropriately.

## Alternatives

- ISO 27001-only; CIS-only without CSF

## Consequences

+ Clear portfolio narrative and mapping model  
− Must manage multiple framework versions carefully
